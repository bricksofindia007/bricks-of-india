## Prompting Principles (apply to every prompt below — not repeated per-row)

1. **Motion only.** Never ask Kling to render text, legible signage, or scene transitions — those are post-production (loop trim, caption burn-in, watermark, and any graphic swaps happen in the moviepy pipeline, not in generation).
2. **Static camera by default** for consistent looping and brand feel.
3. **Same reference photo(s) every generation** — no exceptions, this is what holds the mascot consistent across 27 separate clips.
4. **Standard closing phrase** on every prompt: *"Toy stop-motion aesthetic, [lighting], solid [color] background, smooth motion, no on-screen text."*
5. **Professional render mode, 1080p, for all 27** — Pro plan credit pool comfortably covers this (see math below); no need to ration into Standard mode.
6. **Props with numbers/text** (e.g. "2026"/"2027" signs) stay blank/generic in the Kling generation — the actual digits are added digitally in post, same system as captions.

**Credit math confirmed:** 20 clips at 10s + 7 clips at 5s, Professional mode ≈ 1,880 raw credits; with realistic retries ≈ 2,400-2,500 credits. Comfortably inside Kling Pro's 3,000/month pool.
